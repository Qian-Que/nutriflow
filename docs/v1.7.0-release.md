## NutriFlow 1.7.0 · 营养日记

### 五项优化
1. 识别历史显示正式记录的最新热量与状态，编辑后同步，删除后明确标记。
2. 常用餐食选半份、一份、两份直接记入，不重复调用 AI；日期、餐次、可见范围沿用当前选择。
3. 首页收起已完成任务，历史移至时钟图标；可见范围收为当前状态按钮。
4. 后台任务状态变化即时回传，减少固定刷新等待；管理员新增照片测速及分段耗时，不保存测试记录或改动线上配置。
5. 自动保存后短暂提供“编辑 / 撤销”，不增加强制校对；撤销不会覆盖或删除后来修改过的记录。

### 保持不变
现有配色、Gemini 主备线路、模型设置、包名与签名保持不变。成功识别仍自动保存，上传确认后可以离开应用。

自动模式仍保留判类和识别两步，以免未经真实图片对照就改变识别质量；本次不承诺第三方模型推理时间缩短。

### 验证范围
后端构建、移动端类型检查与回归；浏览器 320/360/390/430/1280 尺寸、日夜主题、历史同步、撤销、常用餐食半份和隐私设置，以及照片测速流程。测试使用隔离账号及模拟 AI，未变更线上 Gemini 配置，未连接 iQOO 真机。

安卓模拟器通过同签名覆盖安装、设置键盘返回、1.3 倍字体、隐私选择、常用餐食半份、保存后撤销，以及上传确认后强制结束应用再打开恢复检查。

Android 7.0 及以上，直接覆盖安装，不要卸载。
