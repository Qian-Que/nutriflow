## NutriFlow 1.4.0

### 新功能
- 识别结果先校对再保存。支持修改食物名称、克数、营养值，整餐减半/加倍，以及补充或移除食物。
- 运动结果支持校对时长、消耗、名称和 MET。低把握识别、图片降级为文字估算时需要明确确认。
- 校对草稿可在关闭或重启后恢复；确认保存沿用固定请求 ID，断网重试不会重复入账。
- 设置新增版本检查与新版 APK 发布页入口，提醒可按版本关闭；检查失败不影响记录，不自动安装。

### 移动端体验
- 安卓键盘避让，记录页输入时收起图表与底栏；校对采用可滚动表单和固定保存栏。
- 优化照片选择、压缩状态与权限提示，取消或失败保留原内容。
- 完善系统返回与运动编辑滚动，有限放行回环地址的 HTTP 调试，公网仍要求 HTTPS。

### 验证
- 后端构建、移动端类型检查及既有权限、AI 解析、任务、图片、离线同步回归通过。
- 新增校对计算、低把握确认、版本来源、缓存和失败退避测试通过。
- 浏览器验证 320/390/1280 宽度、断网响应丢失、重开恢复、图片保存与更新提醒。
- APK 签名、模拟器覆盖安装、登录、键盘、返回及进程重启恢复通过。
- 未连接真实手机；实际相机、厂商键盘和真实 AI 模型效果仍需实机验证。本次不改变线上 AI 配置。

### 安装
Android 7.0 及以上。建议直接覆盖安装，不要先卸载，以保留未同步数据。
旧版没有更新提醒，首次升级到 1.4.0 需要手动下载本 Release 的 APK。
