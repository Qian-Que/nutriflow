# 1.1.0 更新与管理说明

## 全局 AI 设置

使用管理员账号登录，在记录页右上角进入「设置 → 全局 AI」。填写主线路接口地址、模型名称和密钥，可另行启用备用线路。先测试主线路，再选择「保存生效」。后续所有用户的新识别请求均读取服务器保存的配置，无需重新部署或更新 APK。正在执行的识别继续使用请求开始时的配置。

密钥不回显，留空表示保留；更换接口地址时需要重新填写该线路密钥，避免旧密钥被发往新服务商。备用线路使用不同地址时必须单独填写密钥。测试不会发布配置；恢复环境配置会移除在线配置，重新使用 Railway 环境变量。

首次部署将已有的 `18964092532@163.com` 账号绑定为管理员。仅注册这个邮箱不会在后续自动获得管理员权限。若首次部署时数据库中没有这个账号，需要由维护人员在持久数据库的 `app_admins` 表中指定真实用户 ID。

在线配置使用 AES-256-GCM 加密，默认从现有 `JWT_SECRET` 派生加密密钥，也可通过 `AI_SETTINGS_SECRET` 指定独立密钥。保存在线配置后，请保持对应密钥稳定，并备份数据库。Railway 必须继续挂载原有持久 Volume；配置和用户记录都存储在同一个 SQLite 数据库中。

## 记录与界面

- 饮食、运动保存前写入本地待同步队列；退出后重新登录相同账号可继续同步，使用原请求 ID 避免重复保存。
- 文字和照片草稿保留到本机；网络不可用时可以浏览已经缓存的记录。
- 本地待同步队列、草稿与缓存按账号和服务地址隔离。卸载应用或清除应用数据仍会删除未同步的本地内容。
- 记录卡片区分保存状态和估算来源，支持半份、一份、两份、逐项食物克数与餐次调整。
- 增加再记一次、常用餐食快捷输入、周/月饮食回顾，以及个人记录 JSON 导出。
- 日夜主题统一为中性背景，营养图表保留分类配色；底部使用统一图标并适配安全区域，编辑弹窗支持滚动和持续显示数值标签。

## 历史数据与找回密码

默认不再自动删除超过 60 天的记录，体重永久保留。`DATA_RETENTION_DAYS=0` 或未设置表示不清理；显式设置正整数时只清理饮食、运动和相关群组帖子。之前已被删除的数据不会自动恢复。

此前找回密码接口会直接返回验证码。生产环境现已停用这个演示入口；在接入真实邮件服务前，找回密码需要联系维护人员。仅本地非生产环境显式设置 `ALLOW_DEMO_PASSWORD_RESET=true` 才能启用演示流程。
